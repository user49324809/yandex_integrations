# Yandex Reviews Integration

Full-stack демонстрация подключения компании из Яндекс Карт и просмотра её рейтинга и отзывов. Пользователь регистрируется, сохраняет ссылку на компанию и получает отдельную панель с данными.

> Проект использует mock-провайдер: структура интеграции, хранение настроек и интерфейс реализованы полностью, но данные отзывов возвращает локальный `YandexService`, а не официальный API Яндекса.

## Возможности

- регистрация, авторизация и управление профилем;
- сохранение отдельной интеграции для каждого пользователя;
- извлечение числового ID компании из ссылки Яндекс Карт;
- валидация некорректных ссылок;
- отображение рейтинга, количества отзывов и списка отзывов;
- состояния загрузки и ошибки;
- адаптивный интерфейс на Vue 3 и Tailwind CSS.

## Стек

- PHP 8.2 и Laravel 12;
- Vue 3;
- Inertia.js;
- MySQL в production, SQLite in-memory в тестах;
- Vite и Tailwind CSS;
- PHPUnit.

## Локальный запуск

```bash
git clone https://github.com/user49324809/yandex_integrations.git
cd yandex_integrations
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate
```

Запустите backend и frontend в отдельных терминалах:

```bash
php artisan serve
npm run dev
```

После запуска откройте `http://localhost:8000/register`.

## Проверка

```bash
php artisan test
npm run build
```

## Как устроена демонстрационная интеграция

Контроллер сохраняет `yandex_url` и извлечённый `company_id` для текущего пользователя. Страница отзывов запрашивает именно эту запись. `YandexService` изолирует источник данных, поэтому mock-реализацию можно заменить реальным API-клиентом без изменения интерфейса.
